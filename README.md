# Fluxo Fácil

Aplicativo PWA de controle financeiro simples, desenvolvido em HTML, CSS e JavaScript puro.

## Recursos

- Dashboard com saldo, receitas, despesas e resultado mensal
- Cadastro, edição e exclusão de lançamentos
- Categorias personalizadas
- Filtros por mês, tipo, categoria e situação
- Gráficos de análise financeira
- Dados salvos no próprio aparelho com LocalStorage
- Instalação no Android e iPhone
- Funcionamento offline básico
- Atualizações automáticas por service worker

## Publicação

O projeto pode ser hospedado no GitHub Pages, Vercel, Netlify ou em qualquer hospedagem HTTPS.

## Instalação

**Android:** abra no Chrome e toque em **Instalar aplicativo**.

**iPhone/iPad:** abra no Safari, toque em **Compartilhar** e escolha **Adicionar à Tela de Início**.
